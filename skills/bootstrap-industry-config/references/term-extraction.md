# 抽词指南

从转录里抽行业配置，最关键的只有一件事：**判断一个词该不该进"必须由原话支撑"的词表**。

抽多了会让每一份稿子无辜被拒，抽少了等于没防护。所以下面这套判据是本文档的核心。

---

## 一、三个判据（一个词必须三问全过才能进表）

### 判据 1：这个词出现时，通常是谁在说？

- **机构方说的**（销售、顾问、经理、客服）→ 大概率该进表
- **客户说的** → 大概率不该进表

为什么：这类词表防的是「**机构方凭空补出承诺、流程、身份**」。客户说「我上次买过」是事实陈述，不该被要求有原话支撑——它本来就有原话。

### 判据 2：如果报告里写了它，销售会据此采取什么行动？

- 会改变动作（报价、排期、承诺条件、判断客户是老客）→ **该进表**
- 不会改变动作（只是描述性用词）→ **不该进表**

这条能筛掉大部分"行业常用词"。反例：`价格`、`方案`、`咨询`、`产品`——写「谈过三轮价格」不构成任何承诺。

### 判据 3：如果录音里根本没有它却写了，会造成什么后果？

- 会造成**虚假承诺 / 虚假流程 / 错误身份标签** → **强烈该进表**
- 只是措辞不准 → 不该进表

这是最重要的一问。举三个真实后果：

| 词 | 录音里没有却写了，后果是什么 |
|---|---|
| `空腹` | 凭空给客户加了术前禁忌，客户可能照做或恐慌 |
| `体检` | 承诺了一项不存在的流程，客户以为已安排 |
| `首诊` | 给客户贴了"新客"标签，话术策略直接错（其实是老客） |

---

## 二、词的三类（按用途分开，不要混在一个数组里）

### 类型 A：流程 / 承诺词 → `industry_terms`

机构方声称的动作、文件、条件、费用项。

**例（医美）**：`空腹 忌口 发票 体检 保密协议 合同 分期 利息 押金 麻醉 住院`

**例（房产，供参考）**：`定金 首付 网签 过户 税费 贷款 批贷 产权 学区 限购`

### 类型 B：身份词 → 也放 `industry_terms`

给客户贴标签的词。**这类最容易被忽略，但它们直接改变话术策略。**

**例（医美）**：`首诊 新客 首次`

**例（房产）**：`首套 二套 外地户籍 改善型`

### 类型 C：完成态词 → `completion_words`

注意：付款 / 预约 / 完成这三组**跨行业通用**（`已付款`、`已预约`、`已完成`），不必重复写。

**只有你的行业有专属表达时才补**：
- `["已网签", "payment"]`（房产）
- `["已排课", "appointment"]`（教培）
- `["已交定金", "payment"]`（通用，很多行业都有）

第二个元素只能是 `payment` / `appointment` / `treatment` 三者之一（对应通用版的三个交易档）。

---

## 三、明确的禁区

### 不要放这几类

| 类型 | 例子 | 为什么 |
|---|---|---|
| 行业常用词 | `价格` `方案` `产品` `咨询` `服务` | 写它们不构成承诺，但会大量误命中 |
| 客户侧用词 | `我之前来过` `我想想` | 防的是机构方凭空补，不是客户陈述 |
| 单个字 | `单` `价` `费` | 关键词至少 2 字，单字命中率高得离谱 |
| 主观评价词 | `贵` `便宜` `划算` | 写「客户觉得贵」不构成事实断言 |

### 关于「过于常见」的词

如果一个词在转录里出现次数极高（比如 > 50 次），它大概率是行业常用词而不是承诺词。

**判别方法**：问自己「写了它而原文没有，销售会被误导吗？」——如果答案是"不会，只是措辞不准"，删掉它。

## 四、抽取流程（照着做）

1. **先读 `speaker_tags` 分布**，了解这份转录里有几个说话人编号、各多少行。
2. **逐段读分段稿**（每段 100 话轮），边读边记：
   - 机构方说过哪些**流程、文件、条件、费用**？（→ 候选 A 类）
   - 机构方给客户贴过什么**身份标签**？（→ 候选 B 类）
   - 出现过哪些「已经…了」的**完成态表达**？（→ 候选 C 类）
   - 客户问过哪些**必须问清但销售答不上来**的问题？（→ 候选 `required_question_topics`）
3. **对每个候选跑三个判据**，三问全过才留下。
4. 产出的词表**尽量控制在 10–25 个**。超过 30 个基本说明你把常用词也放进去了。

---

## 五、`required_question_topics` 怎么抽

这个不是词表，是**成交前必须问清的问题**。

抽法：扫一遍转录，找出**客户问过但销售没答清**、或者**销售根本没问**的事项。

**例（医美）**：药物过敏、月经生育、既往医美史、职业作息、陪同决策人、手术时间窗

**例（房产）**：购房资格、首付来源、贷款预审、家庭结构、看房时间

判据：**如果这一项没问清就签了，会出什么麻烦？** 会出麻烦的才写进来。

---

## 六、产出前的最后自检

- [ ] 每个词至少 2 个字？
- [ ] `industry_terms` 里没有行业常用词？
- [ ] 完成态词的第二元素都是 `payment` / `appointment` / `treatment`？
- [ ] 有没有两个词互为子串（如「合同」和「购房合同」）？有就只留长的那个。
- [ ] 总数在 10–25 之间？
- [ ] `page.notice` / `page.footer` 里没有残留医美/医疗措辞？

> 抽完之后，脚本会统计每个词在转录里的出现次数。**出现 0 次的词不一定要删**——可能只是这份转录没覆盖到。但它值得你多看一眼。
