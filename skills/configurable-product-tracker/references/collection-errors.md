# 采集失败与停止条件

核验本次 `coverage`、`errors[]`、`cart_price_status` 和原始证据，再决定补采或交付。失败记录保留市场、商品和颜色 URL、镜片路径、失败阶段、原因、时间及截图/正文；重试不覆盖成功记录。

| 情况 | 处理 |
| --- | --- |
| 商品名称、SKU、颜色或购买方式不匹配 | 停止该商品；不把同 ID 的另一市场或相似商品合并。 |
| 弹窗遮挡、网络访问失败或超时 | 确认站点和市场后有限重试；仍不可达则保留缺口和证据，不用历史样例冒充本次采集。 |
| Firmoo 左栏找不到单独镜框图、图片未加载或被延迟弹窗遮挡 | 只从当前商品编号的非模特缩略图选图，确认主图已加载且无遮挡后截图；否则标记 `product_frame_preview_missing`，保留整页截图，不把被遮挡的图片当商品图。 |
| 页面选项与预设不同 | 只展开实际可见选项；记录发现、核价和缺失数。未提供的选项不补零。 |
| 点击技术或材料后没有选中/加购状态 | 记录 `option_not_selectable` 及页面证据；不把配置页小计当购物车价。 |
| 购物车不止一件、币种或 SKU 错误、镜框加镜片不等于单件小计 | 标为 `needs_review`，排除价格统计。税费、运费和优惠成交价继续标未验证。 |
| 批次中断或部分成功 | 保留已成功的路径，只补失败项；队列为空但仍有错误时不能声称全量完成。 |

实际案例提醒：Firmoo 的同数字 ID `4606` 在美国和英国站对应不同商品，跨站须重新核验名称、型号和币种。S939 两站实际各有 22 个二级选项；若仅 20 个购物车核价成功，应同时报告 20 个成功与 2 个缺口。Goldora™ 和 Polarized 曾出现厚度可见但无法选中或继续加购，不能使用左侧配置小计补价。

Firmoo 的已验证二级选项可通过 `scripts/firmoo_lens_tree.py --resume --retry-errors --tier medium` 有界续跑；续跑时档位必须与原主文件的 `coverage_mode` 一致。用 `scripts/firmoo_build_report.py --input 本次输出目录 --product-id 商品ID` 审计缺口；市场、档位与实时输出规则见 [SKILL.md](../SKILL.md)。`skill.run` 是已有数据的离线组装入口；名单采集入口 `skill.run_list` 支持 Firmoo US/USD 和 UK/GBP，但不把两个市场的报价混为同款同币种价格比较。
