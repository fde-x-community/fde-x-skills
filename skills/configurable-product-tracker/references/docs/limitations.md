# 当前限制

本项目聚焦**指定配镜商品在当前支持购买路径中的可核验报价**。下列限制适用于当前交付版本。

## 业务数据

公开的搜索、社媒和站点级数据不能直接证明单品销量、单品流量、渠道归因、广告投入、SEO 效果、市场份额或社媒转化。看板中的相关线索不等于已验证的单品指标。

## 商品与配置

- Vooglam：美国站普通配镜、已核验的默认配色、Single Vision 双眼 SPH/CYL 0.00 与 PD 66。
- Firmoo：美国站或英国站、给定官方商品链接对应的配色、Non-Prescription。
- 太阳镜、预配镜片及其他处方不在上述实时核价范围内。商品身份不明确时需要先澄清。
- `full` 只尝试**当前实现支持范围内**可达的路径，不代表网站全部商品、配色和镜片组合；实际成功与缺口以每次运行结果为准。

## 价格与历史

已核验报价来自购物车商品行的镜框与镜片优惠前单件小计。税费、运费、优惠资格和最终支付价未核验。不同市场的 USD 与 GBP 不自动换算或混合比较。没有采集过的日期不能补出历史价格；只有商品、配置和报价口径一致的观测才可比较变化。

## 运行与解释

浏览器自动化可能受到 DOM 更新、弹窗、网络、加载时间和站点购买流程变化影响。一次运行中有报价，不表示所有计划配置均完成；应同时查看 `run_result.json`、`coverage`、`errors` 与证据。**缺失不等于零，采集失败不等于网站不支持，未观察到不等于不存在。**

具体的采集与数据处理方式见[系统架构](architecture.md)，设计理由见[设计决策](design-decisions.md)。
