# 验收映射与指标口径

交付给评审方看的对账表：每一项验收要求落实在哪个字段、哪一段流程、哪条测试上。写这张表的目的不是自我表扬，是让评审方能**逐条反驳**。

## 二、指标口径（三层，判定线不同）

把「结构合规」与「语义正确」混成一个通过率，会产生一个数学上自欺的指标：**信息缺失样本天然缺字段，要求它们字段齐全等于要求模型臆测。**

- **A 精度层**：结构校验（render 零错误）+ 回归测试全过。这是唯一的硬门槛，必须 100%。
- **B 鲁棒层**：长录音、合并话轮、ASR 噪声、无会话日期、明确拒联等对抗样本。只判「不臆测 + 有未知项 + 有冲突并列」，**不判字段齐全**。
- **C 全量参考**：三份真实录音的语义审计结果（引文命中数、必须修项、建议修项）。仅作参考值报告，不作通过线。

当前状态见 `references/retrospective.md`。任何一次真实运行后都应更新 C 层数字，而不是只留一句「已通过」。
